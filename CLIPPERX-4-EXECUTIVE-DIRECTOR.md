# ClipperX 4.0 — Executive Director

ClipperX 4.0 promotes the application from a fixed sequence-level pipeline to a bounded executive directing system. Existing stages remain visible, but direction, sequence optimization, predictive safety, and model criticism are callable capabilities selected from current evidence.

## Core behavior

- Reconsiders direction when story structure, speaker focus, reactions, or fallback use disagree.
- Reoptimizes the full sequence when a locally good scene creates poor pacing or continuity.
- Re-runs predictive safety when body visibility, subject exit, or detector fragility remains risky.
- Uses a connected model for bounded consequence comparison while deterministic geometry and safety remain authoritative.
- Records the source, reason, alternatives, and outcome of each executive decision.

## Diagnostics

Each run creates a timestamped folder under `runtime/projects/<project-id>/logs/`. The Run Details screen exposes a downloadable diagnostic JSON containing the run summary, executive report, model-use trace, risk report, event trace, and recent engine output. Credentials are never logged.

## 4.1 convergence memory

The executive director now scores every verified plan, remembers the best safe candidate, rejects regressions, restores the best plan when a later route performs worse, and stops when repeated reasoning produces no material gain. The manifest and downloadable diagnostic package include the score history and complete executive decision ledger.

## 4.2 diagnosed body-safe directing

Version 4.2 fixes the failures exposed by a real diagnostic run: safety crop settings are preserved through editorial styling; every repaired scene is simulated again before approval; unresolved P1 body failures block approval and trigger a structural retry; two distant mandatory people use two body-safe regions rather than a midpoint crop; silent action bystanders are removed using object proximity and motion evidence; active speakers remain primary; hurried speaker/reaction moments are limited to two persistent views; and complete-source fallback is available only after evidence-based crops and structural alternatives fail. Missing detections hold the previous valid view, or use a temporary full-source frame when no prior view exists.
